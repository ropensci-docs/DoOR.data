R package containing the data for the Database of Odor Responses. The
corresponding functions package can be found at
<https://github.com/ropensci/DoOR.functions>.

## The DoOR Project

Find more information, precompiled R-packages and a interactive
web-version of the DoOR-Database at: **<http://neuro.uni.kn/DoOR>**

## Install

Either download a packaged version or install *via* `devtools`:
\`\`\`{r} \# install devtools install.packages(“devtools”)
library(devtools)

# install DoOR.data 2.0.1

install_github(“ropensci/DoOR.data”, ref=“v2.0.1”)

# or install the latest version available on Github

install_github(“ropensci/DoOR.data”) \`\`\`
